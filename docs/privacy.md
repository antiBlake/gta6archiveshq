# Privacy policy — GTA6 Archives HQ uploader

The GTA6 Archives HQ uploader is a private tool used only by the owner of the GTA6 Archives HQ YouTube channel.

- It uses YouTube's API (scopes: upload videos, read own channel) to publish Shorts to that one channel.
- It does not collect, store, sell or share data about any other person.
- The sign-in token is stored privately by the owner and can be revoked at any time at https://myaccount.google.com/permissions.

Contact: through the GTA6 Archives HQ YouTube channel.
